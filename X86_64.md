# Benchmark overview — x86_64

> Linux 6.17.0-1020-gcp, x86_64, pinned to cpu 1. Generated 2026-07-12 by
> `compare2upstream/run.sh` (`min_time=1s`,
> `repetitions=5`; cells are medians over config-alternating rounds).
> `fork` is nanofix; `fork-no-simd` is the same code with
> `NANOFIX_DISABLE_SIMD`; `upstream` is jamesdbrock/hffix.
>
> Note: this snapshot predates c3cd292 (reader ctor guard removal); its fork
> iterator rows carry that commit's ~17-20% regression, since fixed and
> A/B-verified back to parity. Refresh on the next run.
